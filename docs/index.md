### Sobre o Projeto
O ProtectKids é uma plataforma desenvolvida na disciplina de Métodos de Desenvolvimento de Software (MDS) da Universidade de Brasília (UnB). 

O sistema tem como objetivo centralizar informações legislativas e facilitar a análise de proposições relacionadas à proteção de crianças e adolescentes. O sistema monitora, classifica e analisa esses dados, apoiando pesquisadores e organizações.

### Funcionalidades
* **Coleta automatizada:** Busca de dados legislativos em fontes oficiais.
* **Processamento de inteiro teor:** Leitura e extração de dados relevantes.
* **Classificação por subtemas:** Organização inteligente das proposições.
* **Dashboard analítico:** Visualização de dados e tendências.
* **Rankings de parlamentares:** Mapeamento de atuação política no tema.

### Objetivos
* Centralizar informações legislativas
* Facilitar análise de proposições
* Identificar tendências legislativas
* Apoiar organizações e pesquisadores
